# v0.1.0 发布验证

- 原生 Swift 测试通过，包括当前会话、十轮上下文、共享记忆、模型档位、气泡完整显示和动画。
- Hook 备用目录去掉开发机路径。源码构建从 `.build/ChimeBuddy.app` 推导自身 checkout，安装包默认不接收 Hook；显式目录必须是绝对路径，规范化后不能是根目录。对应回归通过。个人 Hooks 配置从当前版本的 Git 跟踪中移除，原本机文件保留，信任配置没有改动。
- `scripts/probe-buddy.sh` 三次真实调用通过：用户偏好和项目概况提取、另一测试会话读取概况而不带入原话、伙伴直接回复。测试使用独立临时目录，不向用户聊天或真实共享记忆写入测试数据。
- `scripts/build.sh` 编译通过，原型版本 0.1.0、build 1。Mach-O 为 arm64，`codesign --verify --deep --strict` 通过；仅为 ad-hoc 签名，未进行 Apple 公证。
- ZIP 完整性和 SHA-256 自检通过。分发包仅包含可执行文件、Info.plist、默认角色素材和签名，不包含聊天、画像、凭据或个人 Hooks 配置。
- 支持范围仍为 macOS 14+、默认安装位置的 Codex / ChatGPT 桌面版、单个主窗口及本机会话。没有把本机成功推广为所有客户端版本、Intel Mac 或多窗口兼容承诺。
